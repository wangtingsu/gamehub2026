# 发文图片规范

> 适用于博客 / 攻略 / 评测 / 新闻等所有带正文配图的内容。目标：正文加载快、视觉清晰、无障碍可访问。

## 一、图片格式

按场景选择格式，优先现代格式：

| 场景 | 推荐格式 | 说明 |
|---|---|---|
| 照片 / 游戏截图（彩色） | **WebP**，其次 JPEG | WebP 比 JPEG 小 25%~40%，优先用；老浏览器回退 JPEG |
| 透明图 / Logo / 图标 | WebP（支持透明）或 PNG | 图标类优先 SVG |
| 矢量图 / 示意图 / 图标 | **SVG** | 无限缩放、体积小 |
| 动图 | **避免 GIF** | GIF 体积巨大；改用 WebP 动图或短视频 |
| 禁用 | BMP、TIFF | 体积大、无必要 |

## 二、尺寸

正文栏实际显示宽度约 800px，上传过大尺寸是纯浪费：

- **正文配图**：宽度 **800~1200px**（1200px 已够 Retina 屏 2x 显示）
- **封面图**（列表 / 详情头图）：宽度 **1200~1600px**，比例 **16:9** 或 3:2
- 超过 1920×1080 的图后端会自动压到 1920×1080，但请**作者先自己缩到合理尺寸再上传**，不要直接拖原图

## 三、大小

| 类型 | 上限 | 推荐 |
|---|---|---|
| 单张正文配图 | ≤ 1 MB | ≤ 500 KB |
| 封面图 | ≤ 800 KB | ≤ 400 KB |

- 超过 2 MB 的图上传前先压缩（后端兜底上限是 50 MB，但那不是目标值）
- 压缩工具：Squoosh（网页）、TinyPNG、或本地 `sharp`/`cwebp`

## 四、数量

- 单篇正文配图建议 **5~15 张**；同一张图不要重复贴
- 攻略/评测按步骤配图即可，宁缺毋滥，图片要为内容服务

## 五、可访问性与命名

- **`alt` 文本必填**：无障碍（读屏器）、SEO、加载失败时的占位
  - 例：`![零号安比连携技出招顺序](claret-combo.png)`
  - 纯装饰图可写 `alt=""`，但正文配图一般都需要描述
- **文件名**：英文/拼音 + 连字符，避免中文、空格和特殊字符
  - 例：`claret-build-guide.webp`（不要 `攻略配图 (1).png`）

## 六、上传前自查清单

- [ ] 格式是 WebP / JPEG / PNG / SVG 之一（非 BMP/TIFF/GIF）
- [ ] 宽度已缩到 800~1600px（正文配图 ≤1200px）
- [ ] 单张 ≤ 1 MB（封面 ≤ 800 KB）
- [ ] 已填写 `alt` 描述
- [ ] 文件名无中文/空格

## 七、系统会自动做什么（了解即可）

- 上传时后端用 sharp 压缩：超过 1920×1080 自动缩小，质量 85（配置见 `backend/src/config/index.ts` 的 `upload.image`）
- 正文渲染时 `markdown → HTML` 会统一给图片加 `loading="lazy"` + `decoding="async"`（懒加载 + 异步解码），图片滚动到视口附近才加载
- 所以作者**不需要**手动给图片加任何 HTML 属性，只需保证上面自查清单通过
